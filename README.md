# ساده سكتو — النسخة المجانية (GitHub Pages + Supabase)

نفس الموقع ونفس المميزات (طلبات، حجوزات، شاشة باريستا بصوت وتحديث لحظي، منيو وخصومات وأكواد، مبيعات وتصدير Excel، حسابات وأدوار)، بس من غير سيرفر تديره:
- **GitHub Pages** بيستضيف الصفحات (مجاني).
- **Supabase** بيشيل قاعدة البيانات والدخول والحسابات والتحديث اللحظي (مجاني).

الأسعار والخصومات والصلاحيات كلها بتتحسب وتتراجع جوه قاعدة البيانات نفسها (ملف `supabase/setup.sql`)، فالزبون مش بيقدر يغيّر سعر ولا يدخل كباريستا.

## الإعداد (مرة واحدة، حوالي 20 دقيقة)

### 1) Supabase
1. سجّل على supabase.com وعمل **New project** (اختار أقرب منطقة، واحفظ كلمة سر قاعدة البيانات).
2. من القائمة: **SQL Editor** ← New query ← الصق محتوى `supabase/setup.sql` كله ← **Run**.
3. افتح `supabase/create-admin.sql`، **غيّر كلمة السر** (`CHANGE_ME_NOW`) لكلمة قوية 8 حروف على الأقل، والصقه في SQL Editor وشغّله. ده حساب المدير `admin`. (ماترفعش الملف بعد تعديله على GitHub.)
4. **Authentication ← Sign In / Providers** (أو Settings): اقفل **Allow new users to sign up**. مهم جدًا: الحسابات بتتعمل من لوحة المدير بس.
5. **Project Settings ← API**: انسخ **Project URL** ومفتاح **anon public**.

### 2) ربط الموقع
افتح `public/config.js` وحط القيمتين:
```js
window.SADA_CONFIG = { url: "https://xxxx.supabase.co", anonKey: "eyJ..." };
```
(المفتاح ده عادي يبقى ظاهر. **ماتحطش** مفتاح `service_role` هنا أبدًا.)

وعدّل بيانات الكافيه الحقيقية: `public/index.html` (الموبايل `0100 000 0000`، العنوان، المواعيد، الدليفري) ونفس الرقم في `public/customer.js`.

### 3) GitHub
1. اعمل repository جديد (**Public**، لأن Pages المجانية للـ repo العام).
2. ارفع المشروع كله (بما فيه فولدر `.github`) بـ git:
   ```bash
   git init && git add . && git commit -m "first" && git branch -M main
   git remote add origin https://github.com/اسمك/اسم-الريبو.git && git push -u origin main
   ```
3. **Settings ← Pages ← Source: GitHub Actions**. بعد دقيقة أو اتنين في تاب **Actions** هتلاقي النشر خلص.
4. الرابط: `https://اسمك.github.io/اسم-الريبو/` والباريستا على `.../barista/`.

### 4) أول تشغيل
- ادخل `/barista/` بـ `admin` وكلمة السر اللي حطيتها، واعمل حساب لكل باريستا من تاب «الحسابات».
- جرّب طلب كامل من موبايلك: اطلب، وشوفه عند الباريستا، وخلّيه «جاهز» وتأكد إن الزبون اتنبّه.
- على جهاز الباريستا اضغط زرار «الصوت» مرة بعد فتح الشاشة.

## الصيانة
- **تعديل المنيو والأسعار والأكواد:** من لوحة المدير مباشرة، من غير ما ترفع حاجة.
- **تعديل الموقع نفسه:** عدّل الملفات وارفعها بـ `git push`، والنشر بيتم لوحده.
- **QR الطاولات:** الرابط `https://اسمك.github.io/اسم-الريبو/?t=طاولة 3` بيفتح المنيو والمكان مختار.
- **نسخة احتياطية:** الخطة المجانية في Supabase **مفيهاش باك أب تلقائي**. صدّر المبيعات من تاب المبيعات بانتظام، ومن Table Editor تقدر تصدّر أي جدول CSV.
- **مشروع Supabase المجاني بيتوقف لو محدش استخدمه أسبوع.** الاستخدام اليومي في الكافيه بيمنع ده، ولو وقف تقدر ترجّعه من لوحة Supabase بضغطة.

## ملاحظات
- لو عايز repo خاص (Private) من غير ما تدفع، انشر فولدر `public` على Cloudflare Pages أو Netlify (مجاني) بدل GitHub Pages، والباقي زي ما هو.
- النسخة القديمة (سيرفر Node + Docker) لسه موجودة عندك لو احتجتها.
